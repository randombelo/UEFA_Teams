UEFA Teams Management API

Frontend para gestionar equipos y jugadores de fútbol, consumiendo de forma asíncrona la API FastAPI mediante Axios con una interfaz construida bajo el patrón Atomic Design.

Características

Equipos

Crear, editar, listar y eliminar clubes con búsqueda y paginación.

Jugadores

CRUD completo con filtrado por club y barra de rendimiento.

Documentación

Endpoints, parámetros y ejemplos; algunos con petición real a la API.
  • Gestión de errores controlada con toasts de éxito / error.
  • Búsquedas y paginación en las tablas.
  • Filtrado por tabla relacionada (jugadores por club).
  • Validación en cliente y mapeo de errores 422 del servidor.
